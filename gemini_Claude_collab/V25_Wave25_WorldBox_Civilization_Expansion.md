Humans currently spam campfires because the action mathematically yields `Purpose` unconditionally. We must saturate their neural net so they organically evaluate `Build` as useless when they are already safe.

### File: `crates/emergence-core/src/being/actions.rs`
1. Remove the artificial `score *= 0.1` radius heuristic in `Action::Build`.
2. Rewrite the `Build` score explicitly as a function of unmet needs:
```rust
// If their warmth and safety are already satisfied by the local Comfort grid, building yields 0 value.
let unmet_warmth = (1.0 - beings.hot.needs[being_index][NEED_WARMTH]).max(0.0);
let unmet_safety = (1.0 - beings.hot.needs[being_index][NEED_SAFETY]).max(0.0);

// Only build if you desperately need safety/warmth AND you have stone

    score = 0.0; 
} else {
    score *= (unmet_warmth + unmet_safety) * beings.hot.carry[being_index][1];
}
```
